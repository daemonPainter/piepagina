Just another footnotes plugin

== Description ==

An elegant WordPress plugin built around the personal need for retrocompatibility.

Turns simple, intuitive markup into numerated footnotes. Supports a short number of configurations.
It needs to be compatible with the first footnotes plugin I've ever used, which was [civil footnotes](https://github.com/kadamwhite/civil-footnotes). The double parenthesys style is now a most popular standard within the WordPress community, and that was my starting point.

It shouldn't need much text here, that's what "intuitive" means, right?

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/my-custom-plugin` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
